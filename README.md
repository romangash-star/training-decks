# מצגות להכשרות

מצגות HTML בעברית (reveal.js) עם הטמעות חיות: דשבורדים של Power BI, סרטונים, מפות וכל אתר שמאפשר הטמעה.
כל push ל-`main` מעלה את האתר אוטומטית ל-GitHub Pages.

## מבנה

```
decks/
├── index.html        עמוד ראשי עם רשימת המצגות
├── decks.json        הרשימה שמופיעה בעמוד הראשי
├── _shared/
│   ├── theme.css     העיצוב של כל המצגות (צבעים ופונטים ב-:root)
│   ├── embeds.js     רכיב ההטמעה
│   └── deck.js       הגדרות reveal.js
├── _template/        תבנית למצגת חדשה
└── example/          מצגת דוגמה
```

## מצגת חדשה

1. מעתיקים את `_template` לתיקייה חדשה עם שם באנגלית, למשל `data-workshop-haifa`.
2. עורכים את `index.html` שבתוכה: כותרת, שקפים, הערות דובר.
3. מוסיפים שורה ל-`decks.json`:
   ```json
   { "folder": "data-workshop-haifa", "title": "סדנת נתונים · חיפה", "description": "…", "date": "2026-12" }
   ```

אפשר גם פשוט לבקש מ-Claude Code: "תפתח מצגת חדשה מהתבנית בשם ... עם השקפים האלה".

## סוגי שקפים

| מה | איך |
|---|---|
| שער / סיום | `<section class="slide-cover" data-background-color="var(--c-primary)">` (או `slide-end`) |
| טקסט | `<section>` רגיל עם `h2` ורשימה |
| כרטיסים | `<div class="cards">` ובתוכו `<div class="card">` |
| הופעה בלחיצה | מוסיפים `class="fragment"` לאלמנט |
| הערות דובר | `<aside class="notes">…</aside>` בתוך השקף |
| הטמעה על כל השקף | `<section class="slide-embed">` עם `h2` ו-`<div class="embed embed-fill">` |

## הוספת הטמעה

תמיד אותו רכיב. רק מדביקים את הקישור הרגיל ב-`data-src`:

```html
<div class="embed embed-fill"
     data-src="הקישור"
     data-title="שם התוכן"
     data-fallback="assets/screenshot.png"></div>
```

- **YouTube:** קישור רגיל (`youtube.com/watch?v=…`, ‏`youtu.be/…`, ‏`shorts/…`). אפשר להוסיף `&t=90` כדי להתחיל מדקה וחצי.
- **Vimeo:** קישור רגיל (`vimeo.com/123456`).
- **Power BI:** ב-Power BI: ‏File ← Embed report ← **Publish to web** ← מעתיקים את הקישור (`app.powerbi.com/view?r=…`).
  > Publish to web הופך את הדשבורד לציבורי לכל מי שיש לו את הקישור. לנתונים פנימיים של רשות לא משתמשים בזה. שמים צילום מסך ב-`data-fallback`, משאירים את `data-src` עם קישור הדיווח הרגיל, ומוסיפים `data-type="iframe"`. ככה הצופה יקבל מסך התחברות של Microsoft.
- **קובץ וידאו:** שמים את הקובץ ב-`assets/` וכותבים `data-src="assets/video.mp4"`. עובד גם בלי אינטרנט.
- **כל אתר אחר** (מפת GIS, טופס, Padlet): מדביקים את קישור ההטמעה. אתרים מסוימים חוסמים הטמעה. אז מופיע מסך ריק, ומשתמשים בקישור "פתחו בלשונית חדשה" שמתחת.

מה הרכיב עושה לבד:
- טוען את ההטמעה רק כשמגיעים לשקף. דשבורד שנטען נשאר טעון, כך שבחזרה אליו לא מחכים שוב. דשבורד כבד כדאי לפתוח פעם אחת לפני ההרצאה.
- עוצר סרטונים כשעוברים שקף.
- כשאין אינטרנט או בהדפסה ל-PDF: מציג את צילום המסך מ-`data-fallback` עם כפתור פתיחה.
- מוסיף מתחת שורת מקור עם קישור "פתחו בלשונית חדשה". כדי להסתיר אותה: `data-caption="false"`.

## צפייה במחשב

סרטוני YouTube לא מתנגנים כשפותחים את הקובץ בלחיצה כפולה. צריך להפעיל שרת מקומי מתוך התיקייה `decks`:

```bash
python -m http.server 8766
```

ואז לפתוח את הכתובת `http://localhost:8766`.

## PDF

פותחים את המצגת עם `?print-pdf` בסוף הכתובת, למשל `…/example/?print-pdf`, ואז Ctrl+P ← "שמירה כ-PDF".
בהגדרות ההדפסה בוחרים לרוחב, שוליים "ללא", ומסמנים "גרפיקת רקע".
במקום כל הטמעה יופיע צילום המסך שלה.

## העלאה לאוויר (פעם אחת)

1. יוצרים repo חדש ב-GitHub (למשל `training-decks`). אפשר גם מהטרמינל:
   ```bash
   gh repo create training-decks --public --source . --push
   ```
2. ב-GitHub: ‏Settings ← Pages ← Source: **GitHub Actions**.
3. אחרי דקה-שתיים האתר עולה ב-`https://<שם-משתמש>.github.io/training-decks/`.

מכאן כל `git push` מעדכן את האתר.

> ‏GitHub Pages חינמי רק ל-repo ציבורי. כל הקבצים, כולל צילומי המסך, יהיו גלויים. לא שמים כאן נתונים פנימיים.

## החלפת העיצוב

כל הצבעים, הפונטים והפינות מוגדרים כמשתנים בראש `_shared/theme.css`. כשמושכים את מערכת העיצוב מ-Claude Design, מעדכנים רק אותם, וכל המצגות מתעדכנות.
